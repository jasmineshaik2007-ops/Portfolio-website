# Portfolio Website

A responsive personal portfolio website that showcases my profile, skills, projects, resume, and contact information.

## 🌟 Features

* Personal introduction and profile section
* About Me page
* Projects showcase
* Resume section
* Contact information page
* Responsive design using HTML and CSS
* Profile image and introduction video

## 📂 Project Structure

```text
Portfolio-website/
│
├── index.html          # Home page
├── about.html          # About Me page
├── project.html        # Projects page
├── resume.html         # Resume page
├── contact.html        # Contact page
├── style.css           # Website styling
├── profile.webp        # Profile image
├── my_intro.mp4        # Introduction video
├── background 1.jpg    # Background image
└── resume finall       # Resume document
```

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/jasmineshaik2007-ops/Portfolio-website.git
```

### Open the Project

1. Navigate to the project folder.
2. Open `index.html` in your web browser.

No additional installation or dependencies are required.

### Home
